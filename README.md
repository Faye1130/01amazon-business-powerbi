# 亚马逊经营分析看板

本地 Power BI 看板，包含经营总览、利润、流量、库存、广告、退货、目标管理和搜索词明细，共八页。

## 数据

业务模拟数据，覆盖 2025 年第四季度、18 个 SKU，金额单位为美元，另附同期对照和月度目标。

销售额为折扣后、退款前的订购金额；库存取所选期间最后一天；环比按自然月比较。
