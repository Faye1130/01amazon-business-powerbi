# 亚马逊经营分析 · Power BI

围绕商品经营、利润结构、流量、库存、广告、退货和月度目标建立的可交互分析项目。包含可编辑 Power BI 项目、15 张 CSV 数据表、指标说明与八页实机预览。

> 数据为自主构建的业务模拟数据，不是真实店铺数据，也不是亚马逊官方样例。适用于学习、作品展示和指标建模练习。

![经营总览](docs/images/01.png)

## 页面与业务问题

| 页面 | 主要内容 |
|---|---|
| 经营总览 | 销售额、会话、订单会话比、销量、客单价、月环比及同比对照 |
| 利润分析 | 三级利润结构、费用明细与所选科目的趋势联动 |
| 流量分析 | 自然与广告来源会话、订单、单次会话收入 |
| 库存管理 | 期末库存、滚动销量、覆盖天数、缺货提示和成本口径周转 |
| 广告分析 | 广告销售成本比、投入产出比、点击成本、预算效率 |
| 退货分析 | 原因分布、退款及处理费、固定10天订单观察窗口 |
| 目标管理 | 销售额、销量、利润目标、广告预算及完成情况 |
| 搜索词明细 | 关键词与搜索词粒度、花费、订单及出单率 |

## 本地打开

1. 安装支持 PBIP/PBIR 的 Windows Power BI Desktop。本项目用户截图来自 2.158.1304.0；其他版本尚未逐一测试。
2. 下载或克隆本仓库，先完整解压。不要在压缩包中直接打开项目。
3. 在仓库根目录运行：

```sh
python scripts/configure_paths.py
```

4. 用 Power BI Desktop 打开 `amazon-business.pbip`，点击“刷新”。无需连接亚马逊账号。
5. 数据路径变动后，重新运行上述脚本。脚本会修改模型中的本地 CSV 路径；公开提交前请检查差异，避免提交个人目录。

交付模型以 `__DATA_DIR__` 占位符移除个人路径，首次打开前必须配置。Python 脚本只使用标准库，无需安装额外包。也可在模型文件中把 `__DATA_DIR__` 替换为解压后 data 文件夹的绝对路径，使用正斜杠。

```text
data/                     业务数据及月度目标
scripts/configure_paths.py 本机路径配置
scripts/check_data.py      数据一致性检查
docs/                      指标、数据字典、预览及验证记录

```

## 使用范围

当前为 CSV 文件刷新，不包含 Amazon API、自动调度或文件夹新增报告自动合并。交付包提供固定数据快照；衍生数据与源数据应同步更新，不应只替换部分 CSV 后把结果当作已对账。

本仓库尚未指定开源许可证。Power BI 与 Amazon 名称仅用于说明工具及业务场景；不代表官方项目。主题来源说明见 [THIRD_PARTY.md](docs/THIRD_PARTY.md)。
