# 指标口径与数据假设

## 经营与利润
销售额为订单原价减促销折扣，不减后续退款；订单数与订购件数分别统计。商品会话不是去重店铺访客。订单会话比为订单数除以商品会话数；客单价为销售额除以订单数，件均售价为销售额除以件数。

财务事件收入为正、费用为负，合计为经营贡献利润，未包含固定管理费用与税费。利润率以折扣前销售收入总额为分母。月环比对比前一自然月；缺少上月时不强算。全部比率用合计分子除以合计分母。

## 库存与退货
库存取筛选期间最后一天，不跨日期累加。总库存包括可售、预留与在途；覆盖天数用可售除以近7天日均销量。低于15天提示紧张，15至30天提示关注，超过30天表示覆盖充足，不意味着没有积压风险。

周转天数为期间平均可售及预留库存成本除以净销售成本，再乘期间天数，不含在途。近30天无销量库存不直接等于滞销；没有符合记录显示0，观察不足30天保留提示。

按退货发生日统计的退货件数，与按下单日分组的10天内退货率不同。后者仅纳入截止所选期末已满10天的订单，以其订购件数为分母、下单后10天内退货件数为分子，不是最终退货率。

## 广告与补充数据
广告采用同日成交、当前商品、单次归因的简化假设。ACOS=花费÷归因销售额，ROAS为其反向比率，TACOS=广告花费÷总销售额。无销售额的ACOS留空。

流量来源用固定随机种子拆分原会话，广告来源会话与自然会话合计等于原值，不通过点击数推算。自然订单在本项目假设下为总订单减广告归因订单。去年同期为构建的2024年同月同日基准，其关联日期锚定当前年份，另存同期日期；不是完整的去年交易账。

每个关键词拆为两个搜索词，逐日逐SKU逐关键词保持曝光、点击、花费、订单及归因销售额合计一致。搜索词出单率=有订单词数÷有点击词数；活动＋关键词零订单花费与搜索词零订单花费属于不同粒度。

## 月度目标
基准月销量目标取SKU期初可售数量，10/11/12月分别乘1、1.15、1.1。销售目标为目标销量乘售价，利润目标为销售目标22%，广告预算为销售目标11%。这些为练习计划假设，不使用当月实际结果倒推目标。

完成率=实际÷目标，差额=实际−目标；广告预算显示使用率。目标状态当前按销售额完成率判断，不代表利润等全部目标同时达成。目标页适用于完整月份，尚未设计月中按进度达成率。
