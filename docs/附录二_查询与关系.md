# 附录二：查询、字段类型和模型关系

每张表：主页 → 转换数据 → 新建源 → 空白查询 → 高级编辑器，替换为对应完整代码，然后把查询改为本节表名。代码中的 `__DATA_DIR__` 要替换为你的 data 文件夹绝对路径，例如 `D:/PowerBI/amazon-business-powerbi/data`，保留文件名。日期表也从提供的 CSV 导入。

## 日期

```powerquery
let
 Source = Csv.Document(File.Contents("__DATA_DIR__/00_日期.csv"),[Delimiter=",",Encoding=65001,QuoteStyle=QuoteStyle.Csv]),
 Headers = Table.PromoteHeaders(Source,[PromoteAllScalars=true]),
 Typed = Table.TransformColumnTypes(Headers,{{"日期", type date},{"年", Int64.Type},{"月", Int64.Type},{"年月", type text},{"星期", Int64.Type}},"en-US")
in Typed
```

| 字段 | 模型类型 |
|---|---|
| 日期 | dateTime |
| 年 | int64 |
| 月 | int64 |
| 年月 | string |
| 星期 | int64 |

## 关系设置

下面左侧为维度端（1），右侧为事实端（多）。筛选方向为维度到事实的单向；关系保持活动。日期字段使用日期类型，SKU 使用文本类型。不要把事实表互相连接。

| 维度端 | 事实端 |
|---|---|
| 商品[SKU] | 流量[SKU] |
| 日期[日期] | 流量[日期] |
| 商品[SKU] | 广告[SKU] |
| 日期[日期] | 广告[日期] |
| 商品[SKU] | 退货[SKU] |
| 日期[日期] | 退货[退货日期] |
| 商品[SKU] | 财务[SKU] |
| 日期[日期] | 财务[日期] |
| 商品[SKU] | 库存[SKU] |
| 日期[日期] | 库存[日期] |
| 商品[SKU] | 订单观察[SKU] |
| 日期[日期] | 订单观察[日期] |
| 日期[日期] | 流量来源[日期] |
| 商品[SKU] | 流量来源[SKU] |
| 日期[日期] | 去年同期[日期] |
| 商品[SKU] | 去年同期[SKU] |
| 日期[日期] | 搜索词[日期] |
| 商品[SKU] | 搜索词[SKU] |
| 日期[日期] | 月度目标[日期] |
| 商品[SKU] | 月度目标[SKU] |

“利润层级”和“利润表行”保持断开，不创建关系。它们的筛选通过度量值处理。去年同期表用“日期”连接当前选择期间，“同期日期”记录对应上年日期。月度目标按月初日期连接，只按月份分析，勿把某一天的实际值与整月目标直接比较。
